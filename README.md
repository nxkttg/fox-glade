# 🦊 Лисяча галявина — Three.js

Вечірня лісова галявина: анімована лисиця бігає навколо багаття й розштовхує ящики, гравець кидає м'ячі, а магічний портал телепортує їх у небо. Над галявиною кружляють птахи, у траві мерехтять світлячки.

**Стек:** Three.js r187 · cannon-es (фізика) · lil-gui · Vite · ESLint

## Керування

| Дія | Як |
|---|---|
| Кинути м'яч | клік по сцені (або `Пробіл` — у центр екрана) |
| Погладити лисицю | клік по лисиці — вона зупиняється й озирається |
| Режим лисиці | кнопки Стоїть / Йде / Біжить або `1` `2` `3` |
| Повернути ящики | кнопка 🔄 або `R` |
| Прибрати м'ячі | кнопка 🧹 або `C` |
| Звук | кнопка 🔊 (звуки ударів і порталу синтезуються Web Audio API) |
| Камера | тягни мишею — обертати, колесо — наблизити |
| Налаштування | панель «Налаштування» праворуч угорі |

## Відповідність вимогам

| Вимога | Де і як |
|---|---|
| **Примітиви** | дерева (Cylinder + 2×Cone), каміння (деформований Icosahedron), трава (Cone), багаття (Cylinder, Dodecahedron, Cone), арка порталу (Torus + Box), ящики (Box), м'ячі (Sphere), земля (Circle). Повторювані — через `InstancedMesh` |
| **Складні моделі** | `Fox.glb`: скелетна анімація, 3 кліпи з плавним cross-fade. `Parrot.glb` і `Flamingo.glb`: морф-анімація. Усе через `GLTFLoader` |
| **Матеріали** | `MeshStandardMaterial` з текстурами (map, normalMap, roughnessMap, bumpMap), `MeshPhysicalMaterial` з clearcoat (м'ячі), flatShading (low-poly каміння), vertex/instance colors, `MeshBasicMaterial` з HDR-кольором (полум'я), 3 власні `ShaderMaterial` |
| **Освітлення** | HDR-карта оточення (IBL), `HemisphereLight`, `DirectionalLight` (низьке сонце), `PointLight` у багатті (мерехтить) і в порталі (пульсує) |
| **Тіні** | карта тіней 2048², камера тіні обрізана під галявину, `normalBias` проти shadow acne, `castShadow`/`receiveShadow` налаштовані для кожного об'єкта |
| **Анімація** | `AnimationMixer` (лисиця, птахи), рух лисиці по колу, полум'я, пульсація світла, шейдерні анімації (портал, світлячки, зірки), птахи по орбітах |
| **Фізика** | cannon-es: земля, 10 ящиків, м'ячі, статичні колайдери (дерева, каміння, портал, багаття). Лисиця має кінематичне тіло й штовхає предмети. Портал телепортує м'ячі. Звуки ударів залежать від сили зіткнення |
| **Якісний рендер** | HDR-конвеєр: `HalfFloat` render target + MSAA×4 → `UnrealBloomPass` → `OutputPass` (ACES Filmic tone mapping + sRGB). PMREM-оточення, анізотропна фільтрація текстур, pixelRatio ≤ 2, туман у тон неба, `renderer.compile()` перед стартом |
| **Шейдери** | `shaders/portal`: закручений simplex-шум у полярних координатах. `shaders/fireflies`: частинки, рух і мерехтіння на GPU. `shaders/sky`: градієнт заходу, сонце, мерехтливі зірки |

## Архітектура

```
src/
├── main.js               точка входу (+ очищення при HMR)
├── config.js             усі налаштування та константи
├── core/
│   ├── Experience.js     оркестратор: сцена, камера, цикл, GUI, взаємодія
│   ├── Renderer.js       WebGLRenderer + EffectComposer (bloom, tone mapping)
│   ├── Resources.js      LoadingManager: glTF, HDR, текстури + прогрес
│   ├── Physics.js        світ cannon-es, синхронізація тіл і мешів
│   ├── Pointer.js        курсор; відрізняє клік від перетягування камери
│   └── Sound.js          процедурні звуки (Web Audio API)
├── world/
│   ├── World.js          збирає й оновлює всі об'єкти
│   ├── Sky.js            небо (шейдер)
│   ├── Lights.js         освітлення + HDR-оточення
│   ├── Ground.js, Forest.js, Campfire.js
│   ├── Fox.js, Birds.js  glTF-моделі з анімаціями
│   ├── CrateTower.js, BallLauncher.js   фізичні об'єкти
│   └── Portal.js, Fireflies.js          шейдерні об'єкти
├── shaders/              GLSL-файли (імпортуються через ?raw)
├── ui/HUD.js             інтерфейс, екран завантаження
└── utils/fitToSize.js    нормалізація розміру моделей
```

## Запуск

```bash
npm install
npm run dev       # розробка
npm run lint      # перевірка коду
npm run build     # продакшн-білд у dist/
npm run preview   # перегляд білда
```

## Використання ШІ

Проєкт створено разом із **Claude (Anthropic)**: ШІ допоміг з архітектурою, кодом і шейдерами. Під час перевірки в браузері знайдено й виправлено:
- **Кінематичне тіло лисиці «стрибало»** і розкидало ящики на десятки метрів. Причина: позиція задавалася вручну, а фізичний крок ще раз зсував тіло на його швидкість. Тепер задається лише швидкість до цільової точки.
- **Швидкі м'ячі пролітали крізь портал непоміченими.** Перевірка лише поточної позиції замінена на перевірку перетину площини між кадрами.
- **М'ячі не долітали до порталу** через гравітацію. Збільшено швидкість кидка, додано невеликий розкид.
- **Камера стартувала всередині лісу.** Межу камери прив'язано до радіуса галявини.
